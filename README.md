# Satellite-Based-Flood-Segmentation-Using-Optical-and-SAR-Data
Deep learning-based flood segmentation using Sentinel-2 optical imagery and GF-3 SAR data. Implements a dual-stream SegFormer architecture with cross-modal feature fusion and a high-resolution decoder to improve flood-region localization. Evaluates segmentation performance using mIoU, IoU, precision, recall, and F1-score.
